# CodexGraph-RAG v0.1.0

## Destaques

- Configuração central via `config.yaml` com overrides por env vars.
- Sistema de profiles YAML para domínios (genérico, ERP fiscal, etc.).
- Provedores de LLM/embedding plugáveis: OpenAI, Anthropic, Google, Ollama.
- Parser de código multilinguagem com interface abstrata (Java implementado; Python, TypeScript, Go como stubs).
- Grafo de código construído por orquestrador genérico, sem acoplamento a ERP específico.
- Sync de repositórios com suporte a múltiplos providers VCS (GitHub implementado; GitLab stub).
- Autenticação pluggável: nenhuma, senha ou OAuth Google.

## Breaking changes em relação ao fork original

- O projeto foi renomeado e desacoplado de qualquer ERP ou marca proprietária.
- Domínios específicos devem ser configurados via `profiles/`.
- URLs de repositórios e chaves de API não são mais hardcoded.

## Validações

- `python -m py_compile` nos scripts principais.
- `python -m pytest` na suite completa.
