# Segurança

Se você encontrar uma vulnerabilidade de segurança no CodexGraph-RAG, por favor reporte de forma responsável.

- **Não** abra uma issue pública para vulnerabilidades críticas.
- Envie um e-mail para: seu-email@example.com
- Descreva o problema, versão afetada e passos para reproduzir.
- Aguarde uma resposta antes de divulgar publicamente.

## Boas práticas para usuários

- Nunca versione chaves de API no repositório (use `.env`).
- Não indexe código proprietário sem permissão.
- Mantenha dependências atualizadas.
