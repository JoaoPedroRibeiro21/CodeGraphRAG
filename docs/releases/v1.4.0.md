# VRChat AI v1.4.0

## Destaques

- Retrieval adaptativo com estado conversacional para perguntas multi-turn.
- Orquestração GraphRAG com reescrita contextual, repos esperados e lacunas de evidência.
- Contexto técnico rápido e determinístico para respostas de erro, SQL e fluxo técnico.
- Guardrails SQL para evitar alucinação de tabelas, colunas, joins e filtros não confirmados.
- Validação de evidências documentais antes de usar conteúdo de PDFs.
- Endpoint interno de benchmark em lote para validação sem uso manual da interface.
- Otimizações de latência removendo a análise LLM pesada do caminho padrão.

## Principais Alterações

### Retrieval E Conversa

- Adicionado `adaptive_retrieval.py` com estado de sessão, intenção de retrieval, expansão em grafo e relatório de lacunas.
- Adicionado `retrieval_orchestrator.py` para coordenar PDF, código, histórico e evidências esperadas.
- Persistência do estado de retrieval na sessão Chainlit para melhorar continuidade entre perguntas.
- Melhor suporte para perguntas curtas de sequência, como "E quando falha?" e "E no banco?".

### Segurança De Evidência E SQL

- Adicionado `retrieval_validator.py` para validar evidências documentais antes de citar PDFs.
- Adicionado suporte a extração de colunas confirmadas via `@Column(name=...)` em `code_artifacts.py`.
- Respostas SQL agora separam tabelas confirmadas de colunas confirmadas.
- Quando não há coluna confirmada, o assistente informa explicitamente a ausência de confirmação e orienta inspeção da estrutura.
- O prompt proíbe exemplos SQL com colunas, joins ou filtros não confirmados.

### Performance

- A análise técnica LLM pesada passou a rodar somente quando o usuário pede investigação explicitamente técnica.
- Para perguntas comuns de erro, SQL e fluxo, o assistente usa contexto determinístico extraído do código.
- Redução de timeouts e retries no pipeline técnico interativo.
- Melhor instrumentação de benchmark com `analysis_decision`, tempo não atribuído, p95/p99 e SLA.

Comparado ao baseline inicial, o bloco oculto de aproximadamente 30s nas perguntas de erro/SQL/técnicas foi removido do caminho padrão.

## Upgrade

Para aplicar a versão no container, recrie a imagem do serviço:

```bash
sudo docker compose up -d --build --force-recreate vrchat
```

Depois do rebuild, recomenda-se executar um benchmark de smoke test ou validar perguntas críticas na interface.

## Observações

- Relatórios gerados em `eval/reports/` não são versionados.
- Bancos locais Chroma usados em testes locais não são versionados.
- O endpoint interno de benchmark deve permanecer restrito ao ambiente controlado.
